# Ledgerly — Personal Money Manager Dashboard

A modern, privacy-first personal finance dashboard to track income, expenses, budgets, and savings goals. Built with vanilla HTML5, CSS3, and modern JavaScript with zero build steps or runtime dependencies.

## Features
- **Dashboard Overview**: Financial health metrics (Balance, Income, Expenses, Savings rate) with dynamic SVG sparklines.
- **Interactive Visualizations**:
  - 6-month interactive cash flow chart (Income vs. Expenses + Net line with hover tooltips).
  - Category spending donut chart with percentage breakdown.
- **Transactions Management**: Filter by type, category, date range, or instant text search.
- **Budgets & Spending Limits**: Category-level monthly limits with automated warning states (80% warning, 100%+ over-budget).
- **Savings Goals**: Goal tracker with radial SVG progress rings and quick fund additions/withdrawals.
- **Nutrition & AI Calorie Tracker**: Smart food logging with offline AI calorie/macro estimator, daily deficit goals, and next-meal recommendations.
- **BMI & Health Profile**: Body Mass Index gauge meter with ideal weight calculation, BMR/TDEE tracking, and actionable weight-loss timeline.
- **Multi-Currency Support**: Instant formatting for USD, EUR, GBP, VND, JPY, SGD, and AUD.
- **Privacy & Portability**: Data is stored locally in the browser via `localStorage`. Includes one-click CSV export and demo data reset.
